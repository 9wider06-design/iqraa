محلل السور - موقع ثابت (بدون خادم أو قاعدة بيانات)

الملفات:
  index.html            الموقع كاملًا (القرآن وتخطيط المصحف داخله)
  manifest.webmanifest  بيانات التثبيت كتطبيق
  sw.js                 عامل الخدمة للعمل دون اتصال بعد أول زيارة
  icon.svg / icon-192.png / icon-512.png   الأيقونات

النشر السريع (Netlify):
  1. افتح app.netlify.com/drop
  2. اسحب هذا المجلد (أو الملف المضغوط) إلى الصفحة.
  3. تحصل فورًا على رابط عام. ويمكنك تغيير اسمه من الإعدادات.

بدائل مجانية: GitHub Pages أو Cloudflare Pages؛ ارفع كل الملفات معًا كما هي.

ملاحظات:
  - ارفع الملفات كلها (وليس index.html وحده) ليعمل التثبيت كتطبيق والعمل دون اتصال.
  - عند تحديث الموقع غيّر اسم الإصدار V في sw.js (مثل msr-v4) ليصل التحديث للزوار.
  - يُحفظ كل ما يخص المستخدم (المفضلة والملاحظات والعلامات) على جهازه فقط.
